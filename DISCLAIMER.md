## Mistakes can happen

Lessons, questions, answers, explanations, shortcuts and simulations are written and checked with care. Every generated question's answer is worked out a second, independent way and thrown away if the two disagree, and thousands of automated tests run on every change. Even so, an error can slip through: a wrong answer, a misleading explanation, a figure that does not match its text, or an exam detail that has since changed. If something looks wrong, trust your own working and a standard textbook, and please report it so it can be fixed for everyone.

## Found a mistake? Help fix it

Corrections are welcome and handled in the open. Every report is read, and a confirmed fix is released for everyone and credited to whoever found it.

1. **Report it.** Use "Report a problem with this question" under any solution in the app (it fills in the topic and question for you), or open an issue with the [Content error](https://github.com/SMACAcademy/quantmaster/issues/new?template=content-error.yml) template. Say what is wrong and what it should be.
2. **Show the evidence.** Your working, a reference (a textbook, or the official notification for exam details), or a screenshot. Evidence lets a fix be checked and merged quickly.
3. **Or fix it yourself.** Edit the content and open a pull request describing the change and its evidence. Automated checks run on it, a maintainer reviews it, and once merged it is live within minutes. See [CONTRIBUTING.md](CONTRIBUTING.md).
