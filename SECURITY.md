# Security

QuantMaster is a static site with no accounts, no server and no data sent
anywhere, so the risks are small, but we still want to hear about them.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting instead:
on this repository, open the **Security** tab and choose
**Report a vulnerability**. Only the maintainers can see the report.

Helpful details: what you found, how to reproduce it, and what an attacker could
do with it.

## What is in scope

- The app at https://smacacademy.github.io/quantmaster/ and this source code.
- Examples: script injection through content or URLs, a weakness in the
  Content-Security-Policy, or the service worker serving something it should not.

Problems with GitHub Pages itself should go to GitHub.
